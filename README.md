# amoCRM Sales Analytics

Аналитический проект по данным продаж из amoCRM.

Проект автоматизирует получение данных из amoCRM API, их загрузку в PostgreSQL и расчёт ключевых метрик продаж с использованием Python и SQL.

## Что делает проект

Pipeline работает следующим образом:

**amoCRM API → Python / Pandas → PostgreSQL → SQL-аналитика**

1. Получает новые и изменённые сделки из amoCRM через API.
2. Выполняет первичную обработку данных в Python.
3. Загружает данные в PostgreSQL.
4. При повторном запуске обновляет только новые и изменённые сделки.
5. Выполняет набор SQL-запросов для анализа продаж.
6. Сохраняет рассчитанные метрики в PostgreSQL для формирования истории показателей.

## Аналитические метрики

В проекте рассчитываются:

* воронка продаж по этапам;
* Win Rate по месяцам;
* выручка по месяцам;
* количество новых сделок;
* зависшие сделки;
* среднее время закрытия сделки;
* средний возраст активных сделок;
* средняя стоимость сделки по этапам;
* Win Rate по менеджерам;
* выручка по менеджерам;
* количество дней без движения по активным сделкам;
* средняя стоимость выигранных и проигранных сделок;
* список наиболее старых активных сделок.

## Стек

* **Python** — получение и обработка данных;
* **Pandas** — работа с данными;
* **Requests** — взаимодействие с amoCRM API;
* **SQLAlchemy** — подключение к PostgreSQL;
* **PostgreSQL** — хранение данных и аналитические расчёты;
* **SQL** — расчёт бизнес-метрик;
* **Jupyter Notebook** — разработка и демонстрация pipeline.

## Запуск

Перед запуском необходимо указать параметры подключения:

```python
AMO_SUBDOMAIN = ""
AMO_TOKEN = ""
PG_CONNECTION = ""
TABLE_NAME = ""
```

После этого ячейки ноутбука выполняются последовательно:

1. подключение к amoCRM и PostgreSQL;
2. синхронизация сделок;
3. выполнение SQL-запросов;
4. вывод рассчитанных метрик;
5. сохранение результатов в таблицы истории.

## Примечание

В репозитории не хранятся реальные токены доступа к amoCRM и PostgreSQL.

Ноутбук предназначен для демонстрации подхода к построению аналитического pipeline: от получения данных из CRM до расчёта и сохранения бизнес-метрик.
